# Gemini 接続コード / 한국어 안내
실제 API 호출은 아직 테스트하지 않았습니다. 서버 실행/배포를 하지 않았습니다.
index.html: 기존 로컬 기능 및 AI 전사/코칭 화면. api/: Vercel용 서버 함수. lib/ai.js: 실제 Gemini 호출 코드.
서버 환경변수 AI_ENABLED=true, GEMINI_API_KEY, GEMINI_MODEL, DEMO_ACCESS_TOKEN 필요. 키는 HTML이나 채팅에 넣지 마세요. GEMINI_MODEL은 계정에서 무료 사용 가능한 음성/JSON 지원 모델 ID를 확인해 설정해야 합니다. 무료 프로젝트만 사용하고 결제 계정을 연결하지 마세요. 코드가 계정의 유료 여부를 판별하거나 요금 상한을 강제하지는 못합니다.
시연 접근 암호는 API 키와 다르며 앱에 입력합니다. 공유 암호는 전시용 최소 보호이며 완전한 인증/사용량 제한이 아닙니다. 공개 서비스 전 분산 rate limit/사용량 통제 추가 필요.
음성 2MB 이하, 서버 JSON 본문 3MB, 분석 텍스트 12만 자, 전사 5만 자. 실제 모델의 형식 지원/한도는 테스트 필요. 자동 재시도 없음. API 타임아웃 50초. 비용은 실패/재시도에도 발생할 수 있음. 무료 한도 소진 시 중단하며 타 서비스 전환 없음.
선택 세션 녹음 또는 텍스트를 Gemini로 전송. 원본 PPTX/PDF는 전송 안 함. 수동 전사 수정과 코칭 결과는 IndexedDB에 저장. Google 무료 서비스는 내용 개선/사람 검토 가능. 공개 가능한 본인 샘플만 사용.
분석은 원문 인용 일치 검증 후 최대 3개 카드 저장. 시간 근거/점수 생성 없음. 누락 피드백은 인용 가능한 발언에 한정되므로 전사에 전혀 언급되지 않은 누락을 충분히 찾지 못할 수 있음.
실제 키/모델/HTTPS 배포/한국어 전사/코칭 품질/브라우저 회귀 테스트는 미검증. 서버 테스트 tests/connection.test.cjs. 외부 요청을 모사한 테스트이며 실호출 아님.
